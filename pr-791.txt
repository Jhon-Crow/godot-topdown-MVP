## Описание

Реализован активный предмет "Силовое поле" (Force Field) согласно Issue #676.

При удержании пробела вокруг игрока появляется светящееся силовое поле (голубой энергетический щит). (Отражение снарядов реализовано, но пока не является фокусом данного PR — по просьбе владельца.)

### Задача из обратной связи
По просьбе владельца (Issue comment от 2026-02-15): сделать визуал поля при активации (отражение зарядов вне фокуса пока).

## Анализ первопричины (кейс-стади)

Проблема: При нажатии пробела с выбранным силовым полем ничего не происходило.

Анализ игрового лога (game_log_20260215_231653.txt): В логе есть запись [ActiveItemManager] Active item changed from None to Force Field, но полностью отсутствуют любые записи [Player.ForceField]. Все остальные предметы ([Player.Flashlight], [Player.InvisibilitySuit], и т.д.) логируют инициализацию — а ForceField нет.

Первопричина: Функция _init_force_field() не была вызвана из _ready() игрока на момент тестирования. Без инициализации _force_field_equipped = false (по умолчанию), а _handle_force_field_input() немедленно возвращается из-за этой проверки — нажатие Space не даёт результата.

Исправление: Код добавлен в предыдущих коммитах (50123a17, dd84e96a, 363d92d7, a8278c1c).

Детальный кейс-стади: docs/case-studies/issue-676/README.md

## Функциональность

- Активация: Удерживайте Space для активации щита
- Деактивация: Отпустите Space для отключения щита
- Заряд: 8 секунд полного заряда (расходуется частями)
- 100% отражение снарядов: Пули, осколки, гранаты
- Гранаты без детонации: Наступательные гранаты отскакивают БЕЗ взрыва
- Блокировка урона: Все повреждения блокируются, пока поле активно
- Визуальное предупреждение: Щит мигает при низком заряде (последние 2 секунды)
- Визуал: Голубой светящийся энергетический щит с пульсирующим шейдером

## Техническая реализация

Следует паттерну существующих активных предметов (Flashlight, Invisibility Suit):

1. ActiveItemManager — добавлен FORCE_FIELD enum, данные, иконка, has_force_field(); добавлен в систему разблокировки (unlocked_active_items)
2. player.gd — _init_force_field() и _handle_force_field_input() с логикой удержания клавиши
3. force_field_effect.gd — скрипт эффекта (Node2D) с Area2D для обнаружения снарядов, расходуемым зарядом, шейдером
4. force_field.gdshader — шейдер для светящегося энергетического барьера
