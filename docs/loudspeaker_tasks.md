# Громкоговоритель (Loudspeaker) - Разбивка на задачи

Разбивка функционала активного предмета "Громкоговоритель" на примерно равные по объёму работы задачи.

## Этап 1: Базовая инфраструктура

- [x] **1.1 Регистрация предмета в системе активных предметов**
  - Добавить `LOUDSPEAKER` в `ActiveItemType` enum в `active_item_manager.gd`
  - Добавить данные предмета в `ACTIVE_ITEM_DATA` (имя, иконка, описание без эффекта)
  - Описание: только количество зарядов и активация на пробел
  - Добавить `has_loudspeaker()` метод проверки

- [x] **1.2 Создание системы прогресса предмета**
  - Создать скрипт `loudspeaker_progress.gd` для отслеживания уровня предмета
  - Реализовать подсчёт уровней, пройденных с применением громкоговорителя
  - Сохранение/загрузка прогресса между сессиями
  - Реализовать логику перехода между 7 уровнями развития предмета

## Этап 2: Состояние пацифизма врага

- [x] **2.1 Создание базового состояния пацифизма**
  - Создать `pacifist_state.gd` наследуясь от `EnemyState`
  - Враг не стреляет ни в кого
  - Враг прячется в укрытие (или остаётся в текущем, если уже в укрытии)
  - Враг не выходит из укрытия

- [x] **2.2 Реакция пацифиста на атаку**
  - Если пацифисту нанесён урон - он начинает атаковать атакующего
  - Временный выход из состояния пацифизма при получении урона
  - Сохранение информации об атакующем для целеуказания

- [x] **2.3 Интеграция пацифизма с системой победы**
  - Враг в состоянии пацифиста считается "убитым" для подсчёта завершения уровня
  - Модификация `_check_level_complete()` для учёта пацифистов
  - Тестирование: уровень завершается при живых пацифистах

## Этап 5: Обнаружение целей и применение эффекта

- [ ] **5.1 Проверка попадания врага в сектор**
  - Определение врагов в секторе звукового конуса
  - Учёт расстояния (до 500px для эффекта за укрытием)
  - Фильтрация: только не атакованные игроком враги (не подавленные, не раненые)

- [ ] **5.2 Логика проверки линии видимости и укрытий**
  - Враг в секторе БЕЗ стены - эффект срабатывает
  - Враг в секторе ЗА укрытием, но ближе 500px - эффект срабатывает
  - Враг ЗА стеной (не укрытием) - эффект НЕ срабатывает
  - Проверка для всех врагов в области поражения за одно применение

- [ ] **5.3 Применение эффекта пацифизма с вероятностью**
  - Уровень 1: первое применение - 100%, далее 2%
  - Уровень 2: 5%
  - Уровень 3: 7%
  - Уровень 4-5: 7-11%
  - Уровень 6: 90%
  - За одно применение эффект может сработать на любое количество врагов

- [ ] **6.1 Система отношения врагов к пацифистам**

- [ ] **6.2 Атака пацифистов враждебными врагами**

  - Интеграция с системой целеуказания врага
  - Приоритет целей: игрок vs пацифист

- [ ] **6.3 Распространение пацифизма (уровень 5+)**
  - Когда враг впервые видит пацифиста (прямая видимость)
  - С шансом 11% враг получает состояние пацифиста
  - Цепная реакция через видимость
