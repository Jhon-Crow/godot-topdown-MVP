## Problem

The grenade tutorial hint overlapped the player sprite (#1881).
Additionally, when the grenade tutorial appeared simultaneously with another hint (e.g. scope hint on AK GL), the multi-line grenade hint used a fixed `index * HINT_SPACING` offset (60 px per slot) that ignored actual content height, causing it to slide over the hint below.

## Fix

- `_update_all_hint_positions` now accumulates **actual content height** of each preceding hint instead of using `index * HINT_SPACING`, so every hint is placed strictly above the one below regardless of line count.
- `_update_hint_position` uses the same cumulative-height approach for single-hint updates.
- The `HINT_PLAYER_CLEARANCE` constant keeps all hints above the player sprite, growing upward.
- Merged latest `main` (export-safe `WeaponHintsComponent` for Building and Training Ground scenes from #1879 follow-up).

## Tests

- `test_tutorial_hints_are_bottom_aligned_above_player` — verifies `HINT_PLAYER_CLEARANCE` and height-aware placement.
- `test_tutorial_hints_do_not_use_old_fixed_player_covering_offset` — guards against the old `Vector2(-150, -80 - index * HINT_SPACING)` pattern.
- `test_tutorial_grenade_hint_stacks_above_existing_hints_without_overlap` — new regression test that verifies cumulative stacking is used and `index * HINT_SPACING` is gone.

## Verification

1. Load tutorial level with AK GL — scope hint and grenade hint appear simultaneously; grenade hint should sit cleanly above the scope hint with no overlap.
2. Load tutorial level with any weapon — grenade hint should appear above the player sprite with no overlap.
